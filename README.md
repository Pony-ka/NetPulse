# NetPulse

面向 Windows 的网络质量诊断工具，帮助远程办公用户排查"远程桌面卡顿"问题。

> 🚧 项目处于早期规划阶段。

## 计划功能

- **本机环境**：网卡、Wi-Fi 信号强度与频段、系统代理、TUN 虚拟网卡检测
- **代理感知**：自动遵循系统代理 / 识别 TUN 模式，也可强制直连或自定义代理；每项结果标注实际走的路径
- **出口 IP**：直连与经代理的出口 IP、归属地、ASN、运营商
- **延迟 / 抖动 / 丢包**：ICMP、TCP connect、HTTP 多目标采样（min / avg / p95 / jitter / loss）
- **路由追踪**：MTR 式逐跳延迟、丢包与归属地
- **UDP 检测**：基于 STUN / DNS 的 UDP RTT 与丢包，检测代理是否支持 UDP 转发
- **带宽测速**
- **本地导出**：文本 / JSON，由用户自行决定是否分享

## 隐私

NetPulse **不包含任何数据上传、统计或遥测功能**，所有结果仅保存在本地。
部分检测需要访问公开服务（如出口 IP 查询、STUN、测速），这些目标将在文档中完整列出，并可在设置中关闭或替换。
